# 📁 Инструкция по использованию сканера документов

## 🎯 Что делает скрипт?

Скрипт `scan_documents.py` сканирует папки с документами паломников на вашем компьютере и автоматически определяет у кого полный комплект документов, а у кого чего не хватает.

Результаты сохраняются в файл `document_status.json`, который можно загрузить в CRM-систему для автоматического обновления статусов.

---

## 📂 Структура папок

Скрипт ожидает следующую структуру папок:

```
C:\Документы\Паломники\
├── А01\
│   ├── фото.jpg
│   ├── паспорт.pdf
│   ├── прописка.pdf
│   └── загранпаспорт.pdf
├── А02\
│   ├── фото.jpg
│   └── паспорт.pdf
├── А03\
│   ├── photo.png
│   ├── passport.jpg
│   ├── registration.pdf
│   └── foreign_passport.pdf
└── П-001\
    └── ...
```

### Требования к именам файлов:

Скрипт ищет файлы по ключевым словам в имени (регистр не важен):

**Фото:**
- `фото.jpg`, `фото.png`, `photo.jpeg`
- Любое имя содержащее слово "фото" или "photo"

**Паспорт:**
- `паспорт.pdf`, `паспорт.jpg`, `passport.png`
- Любое имя содержащее слово "паспорт" или "passport"

**Прописка:**
- `прописка.pdf`, `прописка.jpg`, `registration.png`
- Любое имя содержащее слово "прописка" или "registration"

**Загранпаспорт:**
- `загранпаспорт.pdf`, `загран.jpg`, `foreign_passport.png`
- Любое имя содержащее слово "загран" или "foreign"

## 🚀 Как использовать

### Шаг 1: Установите Python

Если у вас ещё не установлен Python:
1. Скачайте с https://www.python.org/downloads/
2. Установите (при установке отметьте "Add Python to PATH")
3. Проверьте установку: откройте командную строку и введите `python --version`

### Шаг 2: Настройте скрипт

Откройте файл `scan_documents.py` в текстовом редакторе (Блокнот, VS Code и т.д.)

Найдите строку 26:
```python
DOCS_FOLDER = r"C:\Документы\Паломники"
```

Измените путь на вашу папку с документами. Например:
```python
DOCS_FOLDER = r"D:\Работа\Паломники\Документы"
```

**Важно:** 
- Используйте `r` перед строкой пути (raw string)
- Для Windows используйте обратные слэши `\`
- Для Mac/Linux используйте прямые слэши `/`

### Шаг 3: Запустите скрипт

**Windows:**
1. Откройте командную строку (Win+R → cmd → Enter)
2. Перейдите в папку со скриптом:
   ```cmd
   cd C:\путь\к\папке\со\скриптом
   ```
3. Запустите:
   ```cmd
   python scan_documents.py
   ```

**Mac/Linux:**
```bash
cd /путь/к/папке/со/скриптом
python3 scan_documents.py
```

### Шаг 4: Проверьте результат

Скрипт выведет в консоль:
```
🔍 Сканирование папки: C:\Документы\Паломники
============================================================

📁 Папка: А01
   ✅ Полный комплект документов
   📄 Найдены:
      • photo: фото.jpg
      • passport: паспорт.pdf
      • registration: прописка.pdf
      • foreign_passport: загранпаспорт.pdf

📁 Папка: А02
   ⚠️  Неполный комплект
   ❌ Отсутствуют: registration, foreign_passport
   📄 Найдены:
      • photo: фото.jpg
      • passport: паспорт.pdf

============================================================
📊 ИТОГО:
   Всего папок: 2
   ✅ Полный комплект: 1
   ⚠️  Неполный комплект: 1
============================================================

💾 Результаты сохранены в файл: document_status.json
```

### Шаг 5: Импортируйте в CRM

1. Откройте CRM-систему в браузере
2. Перейдите на вкладку **"Паломники"**
3. Нажмите кнопку **"Импорт документов"** (фиолетовая кнопка с иконкой папки)
4. В открывшемся окне:
   - **Вариант 1:** Нажмите "Выбрать файл" и загрузите `document_status.json`
   - **Вариант 2:** Откройте файл `document_status.json` в блокноте, скопируйте содержимое и вставьте в текстовое поле
5. Нажмите **"Применить"**

Система автоматически обновит статусы документов для всех паломников!

## ⚙️ Настройка скрипта

### Изменение названий папок

Если ваши папки называются по-другому (например, по ФИО), измените функцию `scan_folder` в скрипте.

### Изменение типов документов

Если вам нужны другие типы документов, измените словарь `DOCUMENT_TYPES`:

```python
DOCUMENT_TYPES = {
    'photo': ['фото', 'photo', 'аватар'],
    'passport': ['паспорт', 'passport', 'внутренний'],
    'registration': ['прописка', 'registration'],
    'foreign_passport': ['загранпаспорт', 'загран', 'международный'],
    'medical_certificate': ['медсправка', 'медицинская', 'справка']  # Новый тип
}
```

### Изменение пути к папке через аргументы

Можно сделать скрипт более гибким, передавая путь как аргумент:

```python
import sys

# В начале файла
if len(sys.argv) > 1:
    DOCS_FOLDER = sys.argv[1]
```

Запуск:
```bash
python scan_documents.py "D:\Мои\Документы\Паломники"
```

## 🔧 Решение проблем

### Проблема: "Папка не найдена"

**Решение:**
- Проверьте что путь указан правильно
- Убедитесь что папка существует
- Проверьте права доступа к папке

### Проблема: "Файлы не найдены"

**Решение:**
- Проверьте имена файлов - они должны содержать ключевые слова
- Убедитесь что файлы находятся непосредственно в папке (не в подпапках)
- Проверьте что файлы не скрытые

### Проблема: "Не найдено паломников при импорте"

**Решение:**
- Убедитесь что номера папок (А01, А02) совпадают с номерами папок в CRM
- Проверьте что в CRM заполнено поле "Номер папки" для паломников

## 💡 Советы

### Автоматизация

Создайте `.bat` файл для быстрого запуска:

**Windows (scan.bat):**
```batch
@echo off
cd /d "%~dp0"
python scan_documents.py
pause
```

Теперь можно просто двойным кликом запускать `scan.bat`

### Регулярное сканирование

Добавьте скрипт в планировщик задач Windows для автоматического запуска:

1. Откройте "Планировщик задач"
2. Создайте новую задачу
3. Настройте триггер (например, каждый день в 18:00)
4. Действие: "Запустить программу" → укажите путь к `scan.bat`

### Резервное копирование

Перед импортом новых статусов рекомендуется сделать резервную копию:
- Настройки → Резервные копии → Создать резервную копию
