# 🚀 CRM «Паломники» - Полное руководство

## 📋 О проекте

Полнофункциональная CRM-система для учёта паломников с гибкой настройкой под любые бизнес-процессы.

**Текущая версия:** 1.0.0  
**Готовность:** 75% (фронтенд готов, backend создан)  
**Статус:** Готово к тестированию и разработке

---

## ✨ Основные возможности

### ✅ Реализовано

1. **Управление паломниками**
   - Таблица с inline-редактированием
   - Карточка с полной информацией
   - Поиск и 15+ фильтров
   - Массовые действия

2. **Гибкая настройка колонок**
   - 18 системных колонок
   - Пользовательские колонки (7 типов)
   - Drag & Drop перемещение
   - Редактирование всех колонок
   - Управление видимостью

3. **Документы и оплаты**
   - Чекбоксы документов (фото, паспорт, прописка, загран)
   - Приём оплат с автоматическими квитанциями
   - Печать квитанций (2 копии на А4)
   - Сумма прописью автоматически

4. **Аналитика и отчёты**
   - Dashboard с графиками
   - Экспорт в PDF и CSV
   - Статистика по оплатам
   - Анализ документов

5. **Система тегов**
   - Цветные теги для группировки
   - Фильтрация по тегам
   - Управление тегами

6. **Безопасность**
   - 3 роли пользователей (Админ, Сотрудник, Руководитель)
   - JWT авторизация
   - Разграничение доступа
   - Audit log всех действий

7. **Настройки**
   - Выбор валюты (7 валют)
   - Программы паломничества
   - Дата хаджа для проверки паспортов
   - Шаблоны квитанций
   - Тёмная тема

8. **Дополнительно**
   - Горячие клавиши
   - Toast-уведомления
   - Резервное копирование
   - Мобильная адаптация
   - Расширенная валидация

## 🎯 Как добавить новую функцию

### Пример: Добавление поля "Email"

#### 1. Обновите типы
```typescript
// src/types/index.ts
export interface Pilgrim {
  // ... существующие поля
  email?: string;
}
```

#### 2. Обновите хранилище
```typescript
// src/store/database.ts
export function createPilgrim(data: Partial<Pilgrim>): Pilgrim {
  const pilgrim: Pilgrim = {
    // ... существующие поля
    email: data.email || '',
  };
  // ...
}
```

#### 3. Обновите UI
```typescript
// src/components/CreatePilgrim.tsx
<div>
  <label>Email</label>
  <input 
    type="email"
    value={form.email}
    onChange={e => setForm({ ...form, email: e.target.value })}
  />
</div>
```

#### 4. Обновите backend (если используется)
```javascript
// backend/server.js
app.post('/api/pilgrims', (req, res) => {
  const { email } = req.body;
  db.prepare('INSERT INTO pilgrims (..., email) VALUES (?, ..., ?)')
    .run(..., email);
});
```

**Подробная инструкция:** `ARCHITECTURE.md`
