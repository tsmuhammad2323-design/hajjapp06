# 🎯 ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ CRM ПАЛОМНИКИ

## 📌 Что у вас есть

Полнофункциональная CRM-система для учёта паломников с:
- ✅ Таблицей с inline-редактированием (как Google Sheets)
- ✅ Карточками паломников с документами и оплатой
- ✅ Ролевой моделью (Админ, Сотрудник, Руководитель)
- ✅ Генерацией квитанций
- ✅ Историей изменений
- ✅ Массовыми операциями
- ✅ Экспортом в CSV
- ✅ Готовым backend для многопользовательской работы
- ✅ Docker-конфигурацией для сервера

## 💻 ВАРИАНТ 2: ЗАПУСК НА ПК (для офиса)

**Для:** Работа на 1-4 компьютерах в офисе

### Требования:
- Windows 10/11, macOS или Linux
- Node.js 18+ ([скачать](https://nodejs.org/))
- 2 ГБ RAM, 2 ГБ свободного места

### Шаг 1: Установите Node.js

1. Перейдите на https://nodejs.org/
2. Скачайте LTS версию (18.x или 20.x)
3. Установите (все настройки по умолчанию)
4. Проверьте установку:
   ```bash
   node --version  # должно показать v18.x.x или выше
   npm --version   # должно показать 9.x.x или выше
   ```

### Шаг 2: Скачайте проект

Если проект в архиве:
```bash
# Распакуйте архив
# Или скопируйте папку проекта в удобное место, например:
# C:\pilgrims-crm (Windows)
# ~/pilgrims-crm (Mac/Linux)
```

### Шаг 3: Запустите backend

Откройте терминал (cmd/PowerShell в Windows, Terminal в Mac/Linux):

```bash
# Перейдите в папку backend
cd pilgrims-crm/backend

# Установите зависимости
npm install

# Создайте файл .env (если нет)
# Windows:
copy .env.example .env
# Mac/Linux:
cp .env.example .env

# Отредактируйте .env и измените JWT_SECRET на случайную строку
# Например: mySecretKey12345

# Запустите сервер
npm start
```

Вы увидите:
```
🚀 Backend сервер запущен на http://localhost:3001
✅ Демо-данные созданы
```

**Не закрывайте это окно!** Сервер должен работать.

### Шаг 4: Откройте фронтенд

**Вариант A: Откройте dist/index.html напрямую**
- Найдите папку `dist` в корне проекта
- Откройте `index.html` в браузере (Chrome, Firefox, Edge)

**Вариант B: Запустите dev-сервер (для разработки)**
```bash
# В НОВОМ терминале (backend уже запущен в первом)
cd pilgrims-crm
npm run dev
```
Откройте http://localhost:5173

### Шаг 5: Войдите в систему

Используйте демо-аккаунты:
```
Администратор: admin / admin123
Сотрудник: employee / emp123
Руководитель: ahmedov / lead123
```

### Шаг 6: Настройте для других компьютеров в сети

Чтобы другие компьютеры в офисе могли подключиться:

1. **Узнайте IP-адрес вашего компьютера:**
   - Windows: `ipconfig` → найдите "IPv4-адрес" (например, 192.168.1.100)
   - Mac/Linux: `ifconfig` или `ip addr`

2. **Другие компьютеры открывают:**
   ```
   http://192.168.1.100:5173
   ```
   (замените на ваш IP)

3. **Если не работает — проверьте firewall:**
   - Windows: Разрешите Node.js в брандмауэре
   - Или временно отключите firewall для теста

### Шаг 7: Автозапуск backend (опционально)

**Windows:**
1. Создайте ярлык для `start-backend.sh` или `npm start` в backend
2. Поместите в `shell:startup` (Win+R → shell:startup)

**Mac/Linux:**
```bash
# Добавьте в crontab
crontab -e
# Добавьте строку:
@reboot cd /path/to/pilgrims-crm/backend && npm start
```

## 🖥️ ВАРИАНТ 3: ЗАПУСК НА СЕРВЕРЕ (постоянный доступ)

**Для:** Круглосуточный доступ из любой точки

### Требования:
- Linux сервер (Ubuntu 22.04 / Debian 12)
- Docker и Docker Compose
- Домен (опционально, например: crm.yourcompany.ru)
- SSL-сертификат (опционально, но рекомендуется)

### Шаг 1: Подготовьте сервер

```bash
# Подключитесь к серверу по SSH
ssh user@your-server-ip

# Обновите систему
sudo apt update && sudo apt upgrade -y

# Установите Docker
sudo apt install docker.io docker-compose -y
sudo systemctl enable docker
sudo systemctl start docker

# Добавьте пользователя в группу docker (чтобы не нужен был sudo)
sudo usermod -aG docker $USER
# Перелогиньтесь
```

### Шаг 2: Скачайте проект на сервер

```bash
# Создайте папку
mkdir ~/pilgrims-crm
cd ~/pilgrims-crm

# Скачайте проект (git или scp)
git clone <url-репозитория> .
# или
scp -r /local/path/pilgrims-crm/* user@server:~/pilgrims-crm/
```

### Шаг 3: Настройте .env

```bash
# Скопируйте пример
cp .env.example .env

# Отредактируйте
nano .env
```

Измените:
```env
# Обязательно измените!
JWT_SECRET=вставьте_длинную_случайную_строку_минимум_32_символа

# Для генерации случайной строки:
# openssl rand -hex 32

# Если нужен Telegram:
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

Сохраните: `Ctrl+O`, `Enter`, `Ctrl+X`

### Шаг 4: Запустите через Docker

```bash
# Соберите и запустите
docker-compose up -d --build

# Проверьте статус
docker-compose ps

# Посмотрите логи
docker-compose logs -f
```

Вы увидите:
```
✅ pilgrims-crm-backend   Up
✅ pilgrims-crm-frontend  Up
```

### Шаг 5: Откройте в браузере

```
http://IP-сервера
```

Например: `http://123.45.67.89`

### Шаг 6: Настройте домен (опционально)

**Если есть домен:**

1. Укажите A-запись на IP сервера у регистратора домена
2. Установите Certbot для HTTPS:
   ```bash
   sudo apt install certbot python3-certbot-nginx -y
   sudo certbot --nginx -d crm.yourcompany.ru
   ```
3. Обновите `nginx.conf` с вашим доменом

### Шаг 7: Настройте автозапуск

Docker уже настроен на автозапуск (`restart: unless-stopped`).

Проверьте:
```bash
sudo systemctl status docker
# Должно быть: active (running)
```

### Шаг 8: Настройте резервное копирование

```bash
# Создайте скрипт бэкапа
nano backup.sh
```

Вставьте:
```bash
#!/bin/bash
DATE=$(date +%Y%m%d)
BACKUP_DIR="/backups"
mkdir -p $BACKUP_DIR

# Бэкап базы
docker-compose exec -T backend cp /app/crm.db /tmp/backup.db
docker-compose cp backend:/tmp/backup.db $BACKUP_DIR/db_$DATE.db

# Бэкап файлов
docker-compose exec -T backend tar czf /tmp/files.tar.gz uploads/
docker-compose cp backend:/tmp/files.tar.gz $BACKUP_DIR/files_$DATE.tar.gz

# Удалить старые (старше 30 дней)
find $BACKUP_DIR -mtime +30 -delete

echo "✅ Backup: $DATE"
```

Сохраните и сделайте исполняемым:
```bash
chmod +x backup.sh
```

Добавьте в cron (ежедневно в 3:00):
```bash
crontab -e
# Добавьте строку:
0 3 * * * /home/user/pilgrims-crm/backup.sh >> /var/log/crm-backup.log 2>&1
```

## 🔧 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: Backend не запускается

**Решение:**
```bash
# Проверьте, не занят ли порт 3001
# Windows:
netstat -ano | findstr :3001
# Linux/Mac:
lsof -i :3001

# Если занят — убейте процесс или измените PORT в .env
```

### Проблема: Frontend не видит backend

**Решение:**
```bash
# Проверьте, что backend запущен
curl http://localhost:3001/api/auth/me
# Должен вернуть 401 (не авторизован), а не "Connection refused"

# Проверьте firewall
# Windows: Разрешите Node.js
# Linux: sudo ufw allow 3001
```

### Проблема: Не работает на других компьютерах

**Решение:**
```bash
# 1. Проверьте IP-адрес
ipconfig  # Windows
ifconfig  # Linux/Mac

# 2. Другие компьютеры открывают: http://ВАШ_IP:5173

# 3. Если не работает — проверьте firewall
# Windows:
# - Панель управления → Брандмауэр → Разрешить приложение
# - Добавьте Node.js

# Linux:
sudo ufw allow 5173
```

### Проблема: Docker не запускается

**Решение:**
```bash
# Проверьте статус
docker-compose ps

# Посмотрите логи
docker-compose logs backend
docker-compose logs frontend

# Пересоберите
docker-compose down
docker-compose up -d --build
```

### Проблема: Не приходят Telegram-уведомления

**Решение:**
```bash
# 1. Проверьте токен бота
curl https://api.telegram.org/botВАШ_ТОКЕН/getMe

# 2. Проверьте Chat ID руководителя
# Руководитель должен написать боту /start
# Затем: curl https://api.telegram.org/botВАШ_ТОКЕН/getUpdates

# 3. Убедитесь, что Chat ID указан в профиле руководителя
```
