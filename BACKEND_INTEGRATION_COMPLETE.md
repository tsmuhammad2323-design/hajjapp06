## 🚀 Как использовать

### Быстрый старт (5 минут):

```bash
# 1. Перейдите в папку backend
cd backend

# 2. Установите зависимости
npm install

# 3. Создайте .env файл
cp .env.example .env
# Отредактируйте JWT_SECRET в .env

# 4. Запустите сервер
npm start
```

Сервер запустится на `http://localhost:3001`

### Подключение frontend:

1. Откройте CRM в браузере
2. **Настройки → Подключение**
3. Включите **"Использовать серверный режим"**
4. Нажмите **"Проверить"**
5. Индикатор станет **зелёным** ✅

### Тестирование многопользовательской работы:

1. Откройте **два разных браузера** (или режим инкогнито)
2. Войдите под разными пользователями:
   - Браузер 1: `admin / admin123`
   - Браузер 2: `employee / emp123`
3. В первом браузере создайте паломника
4. Во втором браузере **обновите страницу** (F5)
5. Паломник появится у обоих пользователей! 🎉

## 🌐 Режимы работы

### Локальный режим (по умолчанию)
- ✅ Данные в localStorage
- ✅ Работает без сервера
- ✅ Быстрый отклик

- ❌ Нет синхронизации

### Серверный режим (новый!)
- ✅ Данные на сервере
- ✅ Доступ с любого ПК
- ✅ Real-time синхронизация
- ✅ Многопользовательская работа
- ⚠️ Нужен запущенный сервер

## 📋 API Endpoints (полный список)

### Авторизация
```
POST   /api/auth/login          - Вход
GET    /api/auth/me             - Текущий пользователь
```

### Паломники
```
GET    /api/pilgrims            - Список паломников
GET    /api/pilgrims/archived   - Архивные паломники
GET    /api/pilgrims/:id        - Получить паломника
POST   /api/pilgrims            - Создать паломника
PATCH  /api/pilgrims/:id        - Обновить паломника
POST   /api/pilgrims/:id/archive   - Архивировать
POST   /api/pilgrims/:id/restore   - Восстановить
DELETE /api/pilgrims/:id        - Удалить паломника
```

### Руководители
```
GET    /api/leaders             - Список руководителей
POST   /api/leaders             - Создать руководителя
DELETE /api/leaders/:id         - Удалить руководителя
```

### Пользователи
```
GET    /api/users               - Список пользователей (админ)
POST   /api/users               - Создать пользователя (админ)
DELETE /api/users/:id           - Удалить пользователя (админ)
```

### Оплаты
```
GET    /api/pilgrims/:id/payments    - История оплат
POST   /api/pilgrims/:id/payments    - Добавить оплату
```

### Квитанции
```
GET    /api/pilgrims/:id/receipts    - Список квитанций
```

### Журнал
```
GET    /api/audit-logs          - Журнал действий
```

### Здоровье
```
GET    /api/health              - Проверка работоспособности
```

## 🐛 Решение проблем

### Backend не запускается
```bash
# Проверьте порт 3001
netstat -ano | findstr :3001  # Windows
lsof -i :3001                 # Linux/Mac

# Если занят, измените PORT в .env
```

### Frontend не подключается
1. Убедитесь, что backend запущен
2. Проверьте URL: `http://localhost:3001`
3. Проверьте консоль браузера (F12) на ошибки CORS
4. Убедитесь, что firewall не блокирует порт

### Ошибка "Недействительный токен"
- Токен истёк (24 часа)
- Войдите снова в систему
- Токен обновится автоматически
