# 🗑️ Система удаления и архивации паломников

## ✅ Что реализовано

### 1. **Мягкое удаление с комментарием**
- При удалении паломника **обязательно** указать причину
- Паломник помечается как удалённый, но не удаляется физически
- Номер папки остаётся зарезервированным
- Сохраняется информация: кто удалил, когда, почему

### 2. **Три раздела паломников**
- **Активные** - действующие паломники
- **Архив** - архивированные паломники (можно восстановить)
- **Удалённые** - удалённые паломники (можно восстановить)

### 3. **Резервирование номеров папок**
- Номера от А001 до А1500
- При удалении номер остаётся зарезервированным
- Визуально видно какие номера заняты, какие удалены, какие свободны
- Новые паломники получают первый свободный номер

### 4. **Восстановление**
- Можно восстановить из архива
- Можно восстановить из удалённых
- При восстановлении номер папки сохраняется

---

## 🎯 Как использовать

### Удаление паломника

1. Найдите паломника в таблице
2. Нажмите кнопку **🗑️ (Удалить)** в колонке "Действия"
3. В модальном окне:
   - Укажите **причину удаления** (обязательно)
   - Примеры: "Дубликат", "Ошибка ввода", "Отмена поездки", "Не вышел на связь"
4. Нажмите **"Удалить"**
5. ✅ Паломник перемещается в раздел "Удалённые"
6. ✅ Номер папки остаётся зарезервированным

### Архивация паломника

1. Найдите паломника в таблице
2. Нажмите кнопку **📦 (Архивировать)** в колонке "Действия"
3. ✅ Паломник перемещается в раздел "Архив"
4. ✅ Номер папки остаётся зарезервированным

### Восстановление из архива

1. Переключитесь на вкладку **"Архив"**
2. Найдите паломника
3. Нажмите кнопку **🔄 (Восстановить)**
4. ✅ Паломник возвращается в активные

### Восстановление из удалённых

1. Переключитесь на вкладку **"Удалённые"**
2. Найдите паломника
3. Нажмите кнопку **🔄 (Восстановить)**
4. ✅ Паломник возвращается в активные
5. ✅ Видна причина удаления и кто удалил

### Просмотр информации об удалении

В разделе "Удалённые" видна дополнительная информация:
- **Кто удалил** - имя пользователя
- **Когда удалил** - дата и время
- **Причина удаления** - комментарий

В toolbar таблицы есть переключатели:

```
[ Активные ] [ 📦 Архив ] [ 🗑️ Удалённые ]
```

- **Активные** - обычные паломники (синяя кнопка)
- **Архив** - архивированные паломники (жёлтая кнопка)
- **Удалённые** - удалённые паломники (красная кнопка)

## 🔢 Система нумерации папок

### Формат номеров
- **А001** - А1500 (три цифры с ведущими нулями)
- Максимум 1500 паломников

### Логика резервирования

**Пример:**
```
А001 - Иванов Иван Иванович (активный)
А002 - ПЕТРОВ ПЕТР ПЕТРОВИЧ (удалён, причина: Дубликат)
А003 - Сидоров Сидор Сидорович (архив)
А004 - свободен
А005 - Николаев Николай Николаевич (активный)
```

**При создании нового паломника:**
- Система найдёт первый свободный номер: **А004**
- Номер А002 останется зарезервированным (удалён)
- Номер А003 останется зарезервированным (архив)

### Визуализация статусов

В таблице:
- **Активные паломники** - обычный белый фон
- **Архивные паломники** - жёлтый фон (при просмотре архива)
- **Удалённые паломники** - красный фон (при просмотре удалённых)

## 🛡️ Безопасность

### Обязательный комментарий
- Нельзя удалить паломника без указания причины
- Кнопка "Удалить" неактивна пока не введён комментарий
- Минимальная длина комментария: 1 символ

### Аудит
- Все удаления логируются в audit log
- Сохраняется: кто, когда, кого, почему
- Можно просмотреть в админ-панели

### Защита от случайного удаления
- Модальное окно с предупреждением
- Обязательное подтверждение
- Возможность восстановления

## 🐛 Решение проблем

### Не могу удалить паломника
**Проблема:** Кнопка "Удалить" не работает

**Решение:**
- Убедитесь что указали причину удаления
- Проверьте права доступа (только admin/employee могут удалять)

### Не вижу раздел "Удалённые"
**Проблема:** Нет кнопки переключения

**Решение:**
- Обновите страницу (F5)
- Проверьте что используете последнюю версию

### Номер папки не резервируется
**Проблема:** После удаления номер используется снова

**Решение:**
- Это нормальное поведение - номера удалённых паломников резервируются
- Проверьте что паломник действительно удалён (в разделе "Удалённые")

### Хочу полностью удалить паломника
**Проблема:** Нужно удалить без возможности восстановления

**Решение:**
- Функция полного удаления будет добавлена позже
- Сейчас можно только мягкое удаление с возможностью восстановления
