## 🐛 Если что-то не работает

### Backend не запускается
```bash
# Проверьте что порт 3001 свободен
netstat -ano | findstr :3001  # Windows
lsof -i :3001                 # Linux/Mac

# Если занят, измените PORT в backend/.env
```

### Frontend не подключается к Backend
1. Убедитесь что backend запущен
2. Проверьте URL в настройках: `http://localhost:3001`
3. Проверьте консоль браузера (F12) на ошибки CORS
4. Перезапустите backend

### Ошибки в консоли
```javascript
// Очистите localStorage
localStorage.clear()

// Перезагрузите страницу
location.reload()
```

### Данные не синхронизируются
1. Проверьте что серверный режим включен
2. Нажмите "Синхронизировать сейчас"
3. Обновите страницу (F5)
